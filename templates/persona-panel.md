# Persona Panel Template

Use when you want a quick multi-persona read before deeper message/product tests.

## Panel Slots
- Early adopter
- Mainstream user
- Pragmatist/budget holder
- Skeptical user
- Edge-case or non-user

## Questions
1. First reaction in one sentence.
2. Would you use it? Why/why not?
3. What would you pay or trade for it?
4. What worries you most?
5. Who would you recommend it to, if anyone?
