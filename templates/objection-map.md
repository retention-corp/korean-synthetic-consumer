# Objection Map Template

Use before sales calls, proposals, stakeholder meetings, or product positioning reviews.

## Objection Categories
- Trust/security
- Time/learning cost
- Price/budget
- Existing workflow inertia
- Internal politics/approval
- Outcome uncertainty

## Persona Tasks
1. List top 3 objections in plain Korean.
2. Rank objections by deal-killing power.
3. Identify proof needed to reduce each objection.
4. Flag any rebuttal that would backfire.
